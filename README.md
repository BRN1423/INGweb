# Mi Portafolio Web

## Descripción

Sitio web de una sola página desarrollado como parte del Taller Integrador del Módulo 1.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Responsive Design

## Secciones

- Inicio
- Sobre mí / Proyecto
- Contacto

## Diseño responsivo

El sitio utiliza CSS Flexbox y cuenta con dos breakpoints:

- 768px para tablets
- 480px para dispositivos móviles

## Accesibilidad

El formulario cuenta con etiquetas `label` asociadas correctamente
a sus respectivos campos mediante los atributos `for` e `id`.

## Validación

El código HTML fue revisado mediante el validador W3C.
